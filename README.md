# WeChatWork-API
> 基于 PC 端 **企业微信** 封装，开发者可通过 **HTTP** 轻松调用，实现企业微信机器人、群管理等强大功能。
---
## 社区版说明
> **社区版限制：**
>
> - **仅支持发送文本消息**
> - **不支持长时间运行**
> - 发送文本接口：`POST http://127.0.0.1:5001/wecom/sendText`
> - 请求头：`Content-Type: application/json`
### 请求参数示例
```json
{
  "to": "S:16888560947xx_7881300701318xx",
  "text": "56465156165"
}
```
### cURL 调用示例
```bash
curl -X POST "http://127.0.0.1:5001/wecom/sendText" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "S:16888560947xx_7881300701318xx",
    "text": "56465156165"
  }'
```
### PowerShell 调用示例
```powershell
Invoke-RestMethod `
  -Uri "http://127.0.0.1:5001/wecom/sendText" `
  -Method Post `
  -ContentType "application/json" `
  -Body '{
    "to": "S:16888560947xx_7881300701318xx",
    "text": "56465156165"
  }'
```

## 使用方法
1. 克隆本项目。
2. 进入项目目录，执行注入命令：
```powershell
.\inject.exe .\libhspv1.dll --port 5001 --receive-url "http://127.0.0.1:9000/wecom/event"
```
### 参数说明
| 参数 | 说明 |
| --- | --- |
| `--port` | API 调用端口 |
| `--receive-url` | 消息推送接收地址 |
> 接口地址中的端口需与 `--port` 参数保持一致。例如使用 `--port 5001` 时，发送文本接口地址为：
>
> `http://127.0.0.1:5001/wecom/sendText`
